// Questions

Before you sign up.

Who is VibeGuard for?
Founders, engineering leads and security teams who own an Android app, a web app, or both — and want a real security posture check on shipped artifacts before attackers do it for them.
Do you need our source code?
No. The static pass and the agent deep-dive work on shipped artifacts: the APK you distribute and the live web target. Static analysis never executes the target at all.
What's in the report?
Findings severity-sorted high → low, each with description, the exact command and its output as evidence, and concrete remediation. Then verified positive controls, then an honest list of what was NOT tested and why. Machine-readable findings.json and an interactive HTML report included.
Is anything run against my target without asking?
No. Active scanning is authorization-gated: the deep-dive agent refuses targets unless you attest authorization in the console. Rates are self-limited, no destructive tests, no credential stuffing, no DoS.
What's the difference between the fast pass and the deep dive?
The fast pass is a seconds-long pure-Python static sweep for an immediate verdict. The deep dive hands the job to the RE-RT agent, which runs the full pipeline — recon, header audits, content discovery, static RE — and writes the complete assessment to disk.
